# 📊 Stock Portfolio Tracker

## 📌 Project Description

This is a simple Stock Portfolio Tracker developed using Python. The program allows users to enter stock names and quantities, calculates the investment for each stock, and displays the total investment.

The portfolio details can also be saved to a `portfolio.txt` file.

## ✨ Features

* Stores stock prices using a Python dictionary.
* Allows users to enter multiple stocks.
* Calculates investment based on stock price and quantity.
* Displays individual stock investment.
* Calculates total investment.
* Handles unavailable stock names.
* Validates the quantity entered by the user.
* Saves portfolio details to a text file.
* Allows the user to finish entering stocks by typing `done`.

## 🛠️ Technologies Used

* Python
* Dictionaries
* Lists
* Loops
* Conditional statements
* Functions such as `append()`
* File handling
* User input
* Arithmetic operations

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the Python program:

```bash
python stock_trscker.py
```

5. Enter the stock name and quantity.
6. Type `done` when you have finished entering stocks.
7. Choose `yes` when asked whether you want to save the portfolio.

## 📄 Portfolio File

When the user chooses to save the portfolio, a `portfolio.txt` file is automatically created.

The file contains the stock name, quantity, price, individual investment, and total investment.

## 🎯 Objective

The objective of this project is to practice Python concepts such as dictionaries, lists, loops, conditional statements, arithmetic operations, user input, and file handling.
